# CrimeWatch SA site

Public draft site for official and labelled crime figures. While the site is a draft,
every page carries a DRAFT banner. Fact labels follow the MediaWatch SA methodology
(Proven, Established, Alleged, Disputed, Not established).

## How the work is checked

Figures and notes are researched and drafted by AI research assistants working under a human
owner. Derived numbers (per-day figures, quarter-on-quarter changes) are AI-derived arithmetic
from the cited official counts and are described that way.

- A researcher finds sources, extracts figures and drafts each page.
- Source reviewers check every new source that is not a major outlet or an official body before it is used.
- An independent critic reviews each change for errors, unsupported claims and privacy problems before it is published.

An external auditor, independent of the researcher, source reviewers and independent critic,
audits the published site and repo. The audit is advisory and doesn't block publishing. Findings
are raised as public issues on this repository, and each one we act on is noted in the commit
history with the commit that fixed it.
